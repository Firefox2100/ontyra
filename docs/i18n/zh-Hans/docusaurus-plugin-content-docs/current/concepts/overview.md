## 记忆的种类 {/* #memory-kinds */}

每条记忆都有自己的种类，以及该种类专属的字段，因此规则不会和观察混在一起。

| 种类 | 它保存什么 |
|---|---|
| `fact` | 关于某个主体的陈述（`subject`、`predicate`、`object`） |
| `directive` | 一条规则：`strength`（`must`、`should`、`prefer`）、`polarity`（`do`、`avoid`）、`rule`、`rationale` |
| `decision` | 选了什么、有哪些备选，以及为什么 |
| `event` | 发生过的事，带时间和结果；其相关性会衰减 |
| `procedure` | 某个触发条件出现时要遵循的步骤 |
| `task` | 要做的事，带截止日期和状态 |
| `lesson` | 一种情境、从中得到的洞见，以及应当怎么做 |

所有种类还都带有 `text`（可读的陈述）、`confidence`、可选的过期时间，以及它们在何处、何时适用（见下文）。

## 提案与审核

智能体从不直接写入记忆。它们发送一个**提案**：由一组操作（`add`、`revise`、`supersede`、`retract`、`link`、`annotate`）组成的列表。守护进程会校验整个提案（字段符合该种类、被引用的记忆存在、所引用的来源确实包含那句引文），然后由**策略**决定：提交、搁置等待审核，或拒绝。被搁置的提案会在运维控制台或通过 API 等待人来处理。见[审核与策略](../guides/review.md)。

修订是不可变的。纠正一条记忆会产生新的修订；替换一条记忆则是取代它。事实是被取代的，而不是衰减的。历史始终可查。

## 记忆适用于哪里

- 锚点把记忆绑定到一个地点：例如 `file://host/path/to/repo`、`ssh://user@host` 这样的 URI，或某个仓库。一个路径可以覆盖其下的一切（`subtree`），也可以只覆盖它自身（`exact`）。
- 作用域：`universal` 记忆在任何地方都成立，并且总是简报的一部分。`contextual` 记忆（默认）只有在有证据表明它适用于此处时才会到达智能体：匹配的锚点、满足的限定条件，或当前情境所涉及的某个概念。既不是 universal 又没有绑定到任何东西的规则是*无作用域*的，写入这样的规则时守护进程会发出警告。`topical` 记忆（关于某个模块或项目的知识）*只有*在与当前工作所关于的对象建立联系时才会到达智能体，无论其文本匹配得多好：一个锚点、工作所在的[已注册资源](../guides/ontology.md)的某个概念，或消息中提到的某个概念（或别名）。topical 记忆必须说明它 `about` 什么。`reference` 记忆则根本不会被召回、简报或检查送达：它们是取自来源的文档和笔记，用 `consult`（或 `search`）去查阅。引用了来源的记忆，除非另有说明，就是 `reference`；一条简短的 topical 概览记忆（“有关于 X 的笔记：去查阅”）会告诉智能体这些资料的存在。
- 限定条件是各种条件（“仅当 python 为 3.12 或更新版本时”），可以是必要条件、充分条件、前置条件、排除条件或触发条件。

## 本体

概念（`python`、`docker`、`localai`）以及它们之间的关系（`is_a`、`part_of`、`same_as`、`replaced_by`、`depends_on`、`disjoint_with`），使得关于某事物的记忆可以从相关事物找到，并为条件提供了词汇。智能体提出本体变更（定义、建立关系、添加别名、编辑、拆分、合并、弃用）；除非某个操作被配置为自动批准，否则由人来批准。见[本体](../guides/ontology.md)。

## 召回 {/* #recall */}

- 简报：会话开始时，此处适用的完整规则集，加上锚定在此处的事实与决策，以及所有到期的事项。
- 召回：每条消息到来时，与文本和上下文相关的记忆。词法检索和嵌入检索找出候选；适用性对它们做过滤；分数做决定；结果被裁剪到词元预算之内。如果最佳匹配不够接近，则什么也不返回。
- 检查：在执行有副作用的操作之前，必须先知道的事情。
- **会话账本**避免同一条记忆在一次会话中被送达两次；如果已送达的记忆后来被修订或撤回，则会发送一次性的更正。

## 可选的模型服务

守护进程只调用下列外部服务，且全部可选：**嵌入**模型、**重排器**，以及**决策模型**（一个小模型，回答前几名候选中哪些对当前情境重要，输出概率而不生成文本）。它们从不改变所存储的内容；无法连接的服务会被跳过。
